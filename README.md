# Student Performance Data Analysis

## Description
Analysis of 3,000+ students to identify factors affecting academic performance (GPA). The dataset includes study hours, absences, tutoring, parental support, and extracurricular activities.

## Key Topics Covered
- Study time vs GPA relationship
- Impact of absences on grades
- Tutoring and parental support effectiveness
- Extracurricular activities influence
- Top vs low performers comparison
- Demographic patterns (age, gender)

## Tech Stack
Python • Pandas • NumPy • Matplotlib • Seaborn
